TTS Feature Comparison: Pocket TTS vs Higgs TTS 3 4B vs Qwen TTS

Tested on spark-ee93 (NVIDIA GB10, aarch64, 121 GiB RAM, 2.6 TiB NVMe). All services were local. Reference voice: jack_h (3.1s, 24 kHz mono). All audio clips share the same prompt text where applicable.

Dates & Times: Readability Probe

Three matched-text, Jack-voice samples per model. The asterisks around the date in the supplied example were Markdown emphasis and were not passed to TTS. The date and weekday combinations were checked. Listen for the weekday/month abbreviation, year, and whether the clock is intelligible and natural; a transcript alone cannot tell us precisely how a clock was spoken.

Provisional result: Higgs and Qwen are close on the calendar-date and clock examples; both preserve substantially more date/time detail than Pocket in Whisper small/medium diagnostics. On the dense ISO-style rollover, Higgs produced a somewhat clearer medium-ASR transcription of the numeric sequence, while both reached the final year. No blind human listening panel was run, and one take per prompt is not a general accuracy ranking. For listener-facing narration, spell out abbreviations and write times in words rather than feeding raw ISO timestamps.

Methodology

All three services were tested on the same GB10 host (121 GiB unified RAM). The jack_h reference was 3.1 s at 24 kHz mono; Pocket and Higgs received that WAV, while Qwen used its named clone. Whisper small supplied diagnostic transcripts, not a definitive pronunciation score. A live post-generation snapshot collected process RSS using ps, Higgs cgroup memory using docker stats, and per-process GPU allocations using nvidia-smi --query-compute-apps=pid,used_gpu_memory. Whole-GPU memory.used returned N/A, but per-process GPU memory was available. On a unified-memory system these metrics are different accounting views of one pool, so their sum is not a defensible total or incremental peak. Pocket and Higgs first-audio probes used different scripts and therefore are not an apples-to-apples latency benchmark.

Limitations

  • Perceived voice quality is subjective. One short Jack reference and three prompt categories cannot establish a general ranking; audition the samples rather than treating model-judge scores as ground truth.
  • Qwen cold-start times are high. The first clone call (~34 s) included lazy loading of the Base model; CustomVoice presets and VoiceDesign load separate model families on first use.
  • Memory is a snapshot, not a peak. Higgs had 16,173 + 1,028 MiB of reported GPU allocations while Docker showed ~1.23 GiB cgroup memory. Qwen Base showed 4,453 MiB GPU allocation and 2,560,976 KiB RSS. These values must not be added together without checking overlap.
  • Qwen cloned voices ignore instruct. The Base cloning model strips style instructions, so tone comes from the reference clip plus punctuation/phrasing only.
  • Higgs tags require exact formatting. The <|sfx:tag|>onomatopoeia rule is unforgiving — a space between tag and onomatopoeia breaks rendering.
  • Pocket has no emotion/style/SFX API. The model is designed for speed and simplicity, not expressivity.
